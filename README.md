# KnightCat AI Studio

**KnightCat AI Studio** — демонстрационный **контент-завод**, который превращает исходную идею в пакет черновиков и публикует одобренный материал только после решения человека.

Первый рабочий контур собран вокруг Telegram и n8n. Пользователь отправляет текст. Фотография в том же сообщении сохраняется в черновик и используется для записи ВКонтакте. После `/approve` сценарий публикует текстовую версию в Telegram и, если фото есть, готовит запись на стену сообщества.

> Статус: демо / прототип. Автоматическая публикация без участия человека отключена.

## Что уже показано

- приём текстового сообщения Telegram;
- опциональная фотография в том же сообщении, сохранение её в черновик;
- генерация структурированного текстового пакета и промпта изображения;
- ручное согласование или отклонение;
- публикация одобренного текста в Telegram;
- загрузка сохранённой фотографии и запись на стену ВКонтакте отдельными HTTP-запросами;
- обработка ошибок OpenRouter, Telegram и ВКонтакте;
- разделение веток «черновик», «одобрение», «отклонение» и «ошибка».

Публикация в отдельный канал требует корректного `chat_id` и прав бота. Качество текста и изображения зависит от выбранных моделей и промпта; итоговый материал проверяет автор.

Локальный workflow готовит запись ВКонтакте из текста черновика и фотографии того же сообщения. Условия, credentials и проверка описаны в [n8n/README.md](n8n/README.md). Активный сценарий n8n этим файлом сам не перезаписывается.

## Как устроен поток

```text
Запрос в Telegram
→ нормализация и проверка доступа
→ генерация пакета контента
→ валидация JSON
→ черновик в Telegram
→ решение человека
→ публикация текста в Telegram
→ загрузка фотографии черновика и запись на стену ВКонтакте
→ подтверждение или сообщение об ошибке
```

## Быстрый старт

1. Импортируйте [минимальный workflow](n8n/workflows/knightcat-minimal-telegram.json) в n8n.
2. Подключите Telegram Bot API и OpenRouter через credentials n8n.
3. Укажите разрешённые аккаунты и целевой `chat_id`.
4. Пройдите сценарии из [smoke-тестов](n8n/tests/smoke-cases.json).
5. Оставьте автоматическую публикацию выключенной до завершения проверки.

Подробная настройка описана в [n8n/README.md](n8n/README.md), требования и критерии приёмки — в [техническом задании](docs/TECHNICAL_SPEC.md).

## Границы MVP

Текущий MVP принимает текстовое сообщение Telegram и, по желанию, одну фотографию в том же сообщении. Фотография сохраняется в черновик и идёт на стену ВКонтакте. Сценарий формирует анализ и черновики для нескольких платформ, проверяет JSON и лимиты длины, затем публикует одобренный текст сначала в Telegram.

Разбор URL, распознавание голоса и автоматическая генерация изображения в этот контур не входят: это следующие этапы. Журналирование, метрики и полноценная работа с несколькими каналами тоже остаются впереди.

# KnightCat AI Studio

**KnightCat AI Studio** — демонстрационный **контент-завод**, который превращает исходную идею в готовый пакет контента: текст, визуальный промпт, изображение и публикацию после подтверждения человека.

Первый рабочий контур контент-завода собран вокруг Telegram и n8n. Пользователь отправляет тему, получает черновик на проверку, принимает или отклоняет его, после чего сценарий генерирует изображение и готовит материал к отправке в целевой Telegram-канал.

> Статус: демо / прототип. Автоматическая публикация без участия человека отключена.

## Что уже показано

- приём текстового запроса через Telegram;
- генерация структурированного поста;
- формирование промпта для изображения;
- ручное согласование или отклонение;
- генерация PNG и подготовка бинарного файла;
- обработка ошибок OpenRouter и Telegram;
- разделение веток «черновик», «одобрение», «отклонение» и «ошибка».

Публикация в отдельный канал требует корректного `chat_id` и прав бота. Качество текста и изображения зависит от выбранных моделей и промпта; итоговый материал проверяет автор.

## Как устроен поток

```text
Запрос в Telegram
→ нормализация и проверка доступа
→ генерация пакета контента
→ валидация JSON
→ черновик в Telegram
→ решение человека
→ генерация изображения
→ публикация или сообщение об ошибке
```

## Быстрый старт

1. Импортируйте [минимальный workflow](n8n/workflows/knightcat-minimal-telegram.json) в n8n.
2. Подключите Telegram Bot API и OpenRouter через credentials n8n.
3. Укажите разрешённые аккаунты и целевой `chat_id`.
4. Пройдите сценарии из [smoke-тестов](n8n/tests/smoke-cases.json).
5. Оставьте автоматическую публикацию выключенной до завершения проверки.

Подробная настройка описана в [n8n/README.md](n8n/README.md), требования и критерии приёмки — в [техническом задании](docs/TECHNICAL_SPEC.md).

## Границы MVP

MVP принимает текст, URL и голосовые сообщения, формирует анализ и черновики для нескольких платформ, валидирует единый JSON-пакет и публикует одобренный материал сначала в Telegram. Журналирование, метрики, повторная отправка и полноценная работа с несколькими каналами остаются следующими этапами.

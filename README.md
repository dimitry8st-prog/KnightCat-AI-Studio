# KnightCat AI Studio

**KnightCat AI Studio** — AI-конвейер для подготовки контента из одной исходной идеи для Telegram, Instagram, X, VK и TikTok.

Проект принимает текст, ссылку, изображение, PDF или голосовое сообщение, извлекает смысл, создаёт адаптированные публикации и визуальный промпт, собирает результат в единый JSON-пакет и передаёт его на проверку перед публикацией.

## Текущий статус

Проект находится на стадии технического проектирования.

- [Техническое задание](docs/TECHNICAL_SPEC.md)
- Реализация n8n workflow — следующий этап
- Автоматическая публикация по умолчанию отключена
- Первый целевой канал публикации — Telegram

## Принцип работы

```text
Источник → Нормализация → Анализ → Генерация контента
→ Проверка качества → Одобрение человеком → Публикация → Аналитика
```

## MVP

Первая версия должна:

1. принимать текст, URL и голосовые сообщения через Telegram;
2. формировать структурированный анализ;
3. создавать черновики для пяти платформ;
4. генерировать промпт для изображения;
5. валидировать итоговый JSON;
6. отправлять пакет на ручное одобрение;
7. публиковать одобренный материал в Telegram;
8. сохранять статус, ошибки и метрики выполнения.

Подробные требования, архитектура, тесты и критерии приёмки описаны в техническом задании.
